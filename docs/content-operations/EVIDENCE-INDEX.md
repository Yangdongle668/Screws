## 更新办法

1. 以 ID 收集材料。内部原件留在企业受控存储；这里只记录脱敏摘要、版本、核对日期、适用产品／工序和披露授权状态。
2. 网站文字、示意图片和空白模板不会自动升级为企业交付证明；技术引用也不会自动证明公司具备某项设备或认证。
3. 新资料经企业确认后更新 scripts/core-evidence-notes.mjs，必要时更新 COMPANY-FACTS.md；运行 node scripts/build-core-audit.mjs 更新所有索引。
4. 按 evidence-index.json 的 relatedPaths 找受影响页面；在内容源中修改英文，确认后同步译文。资料索引本身不修改前台。
5. 产品或工艺发生变化时复核；月度检查失效资料。证书若未来存在，另记录有效期与范围。职责是建议角色，不是已确认的员工安排。
