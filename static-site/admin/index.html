    SMTP转接服务部署设置

    当前网站托管不能直连SMTP，需要在支持SMTP的服务器部署随项目提供的转接服务。未接通时可以保存SMTP信息，但不能启用发送，也不会显示为发送正常。

    转接服务必须由你控制，SMTP凭据会通过HTTPS发送给该服务。服务接收经认证的请求，并验证SMTP目标、TLS证书和发送幂等编号。部署包与说明位于项目smtp-bridge目录；需先部署到你控制的服务器。
