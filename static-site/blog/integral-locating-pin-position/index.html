Integral locating pins: coordinating pin and screw datums

Combining a small locating pin with a screw can reduce separate components, but the locating and clamping functions still need distinct specifications.

By Theo Wan • ZUFEK Technical Editorial • Published October 29, 2026

RELATED PRODUCTScrews with Integral Locating Pins ↗

Identify which feature locates

Explain whether the pin establishes lateral position while the screw supplies clamp load, or whether another feature controls the assembly. Include the mating hole and seating surface. Without that information, a manufacturer cannot tell which relationships are functionally critical.

Define the pin position and orientation

Specify pin diameter, projection and position relative to the selected reference features. An offset pin may also need angular orientation to the head or drive. Use a clear datum scheme so machining and inspection establish the same relationship.

Working on this type of part? Explore our screws with integral locating pins and include the functional requirements in your RFQ.

Review the installation sequence

Show how the pin enters its hole before or during thread engagement. Consider surrounding clearance and any movement available in the mating components. A single component can be dimensionally correct but difficult to install if the assembly sequence was not considered.

Check the complete functional geometry

Inspect pin dimensions, position and relevant seating faces. If a functional assembly check is used, document the mating reference and acceptance method. Do not rely on the appearance of the pin or successful thread engagement as proof that the locating requirement is satisfied.

Specification example

For a screw with a pin under its flange, provide the hole pattern and the flange seating face. These details allow the pin location to be evaluated in the same assembly condition in which it will operate.

RFQ checklist

  • Locating versus clamping function
  • Pin diameter and projection
  • Position and angular datums
  • Mating hole and assembly sequence
  • Functional acceptance reference
