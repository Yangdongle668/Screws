非标紧固件图纸评审：从询价到生产放行的检查清单

图纸审查应将不完整的请求转变为受控的制造和验收包。本指南适用于准备定制螺丝询价的工程师或买家。它的输出不是首选尺寸的通用列表。它记录了零件的功能、供应商必须交付的内容以及哪些未解决的决定阻止放行。将其与现有的询价清单一起使用，而不是取代设备设计师的计算或适用的规范。

Theo Wan · 2026-10-30

步骤1：识别受控定义

记录零件编号、图纸修订、单位系统、日期和负责的设计联系人。检查模型、二维图、样品和采购说明书描述的版本是否一致。如果他们不同意，请确定哪个文件负责。样本可以揭示几何形状，但不能可靠地建立隐藏的特征、材料状态或预期的公差基础。如果唯一的参考是样品，请说明在批准生产图纸之前必须确认什么。

创建一个文档登记册，其中包含文档名称、修订、目的和审批状态列。标记过时的版本，以便它们不会与实时定义混淆。如果供应商创建了制造图纸，则在其成为订购参考之前需要获得批准。采购方应该能够回答一个简单的问题：将使用哪个确切的定义来判断交付的部件？

步骤2：解释汇编函数

写一段描述紧固件是否夹紧、定位、枢转、调整、保留或提供定义的通道。包括关系不明显的配合部分部分。确定固定的表面和必须保持自由的表面。对于带肩螺钉，显示配合孔和轴向叠层。对于自攻螺钉，请显示固定接口和允许的移动。对于空心零件，定义通道和任何特定于接口的要求。

请勿要求供应商从产品名称推断额定载荷、密封设计或安装扭矩。这些要求需要经过批准的工程基础。如果需要可制造性提案，请说明哪些功能可以更改以及谁可以批准它们。这可以防止供应商的建议被误认为是对完整设备设计的批准。

步骤3：区分关键特征和背景尺寸

列出控制功能的维度和关系。对于每一项，记录其目的、公差基础、最终条件和建议的检验方法。直径公差不会自动定义与其他特征的对齐。总长度不能建立可用的螺纹接合。一般边缘注释可能无法解释不可接近的孔交叉点处的可接受条件。在到处添加更严格的公差之前解决这些区别。

使用包含以下字段的审查表：特征标识符、绘图参考、功能原因、验收要求、测量条件、建议的方法和开放问题。避免在方法栏中填写无法评估实际要求的仪器名称。光学轮廓、螺纹量规和装配试验回答了不同的问题。只有当能够合理地获得所需的证据时，审查才算完成。

步骤4：指定螺纹和配合细节

确定螺纹系统、尺寸、螺距、公差等级（如果适用）、可用螺纹长度和所需的验收条件。当浮雕、跳动或不完整螺纹区域影响落座或啮合时，显示它们。对于螺柱上的混合螺纹，明确标识每一端。对于盲接收功能，区分可用深度和有用接合，并分别检查底部和座位。

如果螺纹特殊，请提供受控轮廓或合适的参考并讨论验收方法。供应商不必决定“超细”、“紧密螺纹”或“与样品相似”的含义。如果配合零件用于功能评估，请确定其修订和限制。使用一个不受控制的样品进行的成功试验并不能取代规定的生产验收基础。

步骤5：连接材料、处理和尺寸

指定材料名称和条件、所需的成品性能和表面处理范围。保持这些连接但又分开。仅原始等级名称并不能确定由其制成的每个紧固件的成品强度。确定热处理、涂层或其他可能影响验收的操作后适用的尺寸。注意排除在处理之外的任何表面以及排除的依据。

要求供应商确定工艺路线假设和任何需要图纸批准的津贴。如果这些决定影响装配或加工，则审查不应以“材料和表面处理稍后决定”结束。对于相关背景，NASA 的紧固件设计手册讨论了材料选择、涂层、螺纹和接头注意事项。它是一般参考，而不是当前特定于产品的批准或定制组件的通用扭矩值来源。

步骤6：定义证据和释放条件

商定样品范围、检验记录、所需材料或处理文件、批次标识和包装。说明某项特性是否需要逐件检查或商定的抽样安排。不要在没有指明特征和方法的情况下使用“全面检查”。确定任何破坏性测试或外部评估以及由谁来安排它们。当组件验收需要不同的证据时，请将组件验收与装配验证分开。

使用决策日志完成审核。每个未清项目都需要一个所有者、一个必需的答案和一个放行结果。合理的状态集是开放的、提议的、批准的或不适用的。记录任何偏差的批准参考。当功能接口仍标记为“供应商决定”时，请勿放行产品，除非已明确同意该责任范围。

可复制的放行记录

每个决策使用一行：部分和修订；装配参考；特征或要求；供应商提案；对功能的影响；所需证据；负责审批人；审批参考资料；释放状态。附上最终图纸和接受的检验计划。与采购包裹一起保留记录，以便后来的买家了解订单的依据。

生成的包应该让新的审阅者确定必须做什么、如何检查关键功能以及允许进行哪些更改。这是对良好绘图审查的实际考验。它比一份长长的清单更有价值，清单上的方框被标记为完整，而重要的组装假设却没有记录下来。
