DRIVE INTERFACE GUIDE

The right recess.
The matching tool.

Specify the actual interface and available assembly access. A drive name or visual resemblance is not a complete tool-fit definition.

Drive familyWhat to distinguishDrawing inputs
Pin-in six-lobeSix-lobe recess with a center pinPin dimensions, lobe profile, depth and matched tool clearance
Y-type / tri-wing-styleNamed interfaces can have different blade profilesSupply the exact profile; do not treat all Y-like recesses as interchangeable
Five-lobe / pentalobeFive-lobe profiles differ from six-lobe drivesSpecify the actual drawing or recognized interface
Two-hole spanner / snake-eyeA pair of holes provides the tool engagementHole diameter, center spacing and depth
Triangle / squarePolygonal interfaces for the selected toolAcross-flat dimensions, corner form and engagement depth
Combination driveTwo defined drive geometries in one headShow both interfaces and allowable combined depth
Knurled hand gripStraight or diamond pattern for manual operationGrip dimensions and whether an additional socket is needed
Tamper-resistant drives discourage casual access; they do not guarantee that a fastener cannot be removed. Torque capacity and cam-out behavior depend on the actual profile, tool, material and engagement.
