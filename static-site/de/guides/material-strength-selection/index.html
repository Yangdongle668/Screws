Treffen Sie gemeinsam die Wahl.

Ein Materialname ist der Anfang einer Spezifikation. Ob es geeignet ist, hängt von den erforderlichen Endeigenschaften, der Umgebung und der Montage ab.

1. Geben Sie die Funktion vor der Legierung an

Trennen Sie die tragende Funktion von der Positionierung, Einstellung, elektrischen Kontaktierung oder einem Durchgang. Geben Sie die Umgebung, die passenden Metalle und die Reinigungsbedingungen an. Eine Schraube, die für eine optische Justierung verwendet wird, kann eine andere Priorität haben als eine Klemme in einem Outdoor-Gehäuse, auch wenn der Umriss ähnlich aussieht.

2. Halten Sie die Festigkeitswerte an ihrer Basis fest

Geben Sie an, ob die angegebene Zahl Metallrohmaterial oder eine fertige Verbindungselementklasse beschreibt. Notieren Sie Sorte, Härte- oder Wärmebehandlungszustand, Produktform und die anwendbare Spezifikation. Übertragen Sie einen Lagerzugwert nicht direkt auf die montierte Tragfähigkeit. Der Gewindeeingriff im Gegenstück und Gegenstück kann die Verbindung bestimmen.

3. Überprüfen Sie Oberflächen- und Montageeffekte

Eine Beschichtung kann Abmessungen und Reibung verändern. Edelstahl, Titan und andere Kombinationen erfordern möglicherweise eine baugruppenspezifische Überprüfung der Verschleißfestigkeit. Eine Schmierung oder ein Beschichtungswechsel muss mit dem Montageprozess koordiniert werden und darf nicht hinzugefügt werden, nachdem eine Drehmomentanforderung vereinbart wurde. Bei der Oberflächenbearbeitung hochfester Stähle ist auch eine Wasserstoffgefährdungsbeurteilung für die eigentliche Strecke erforderlich.

4. Beweise und Änderungen genehmigen

Geben Sie die Materialdokumentation, die endgültigen mechanischen Anforderungen, die Maßabnahme und alle für den Auftrag erforderlichen Beschichtungs- oder Funktionsprüfungen an. Vereinbaren Sie, wer eine alternative Note oder Bedingung genehmigt. Die Mustergenehmigung sollte das genaue Material und die Prozessrevision angeben, damit eine spätere Substitution sichtbar ist.

Anschaulicher Vergleich

Vergleichen Sie für eine Schraube zur Befestigung einer Außenabdeckung eine spezifizierte Lösung aus rostfreiem Stahl mit einer Lösung aus beschichtetem Stahl in Bezug auf die gleiche Umgebung, die gleichen Verbindungsanforderungen und den gleichen Abnahmeplan. Wählen Sie nicht nur die Farbe oder eine einzelne Nennstärkezahl aus. Bei der Überprüfung sollten Korrosion, Eingriff, Reibung, sichtbarer Zustand und erforderliche Aufzeichnungen vor einem endgültigen Angebot geklärt werden.
